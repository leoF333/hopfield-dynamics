# Primary lab worklogs

These are the original working records of the research, kept verbatim. **They are written in
French**, because that is how they were written at the time; the English documentation in
`docs/` is derived from them, not the other way round.

They are included because they are the authoritative source for protocols, dates, run times,
abandoned hypotheses and per-experiment verdicts — the things a paper's methods section
compresses away.

| File | What it covers |
|---|---|
| `CYCLE_worklog.md` | The main journal. §3 the exact reduction, §4 Floquet methodology, §6 the experiment log E1–E37 with protocols and numbers, §10 figure index, §11 code index, §12 open questions, §13 decision log, plus three appendices. Start here. |
| `REPORT_static_bifurcation.md` | Static folds, `λ_c(α)`, `τ`-independence, the Hopf crossover. |
| `REPORT_attracteurs.md` | Basins, the nature of the chaos, the SRB / no-aging result. |
| `REPORT_faible_tau.md` | The short-delay regime and how the cycle dies there. |
| `FLOQUET_methodology.md` | The Floquet algorithm and its validations, in full. |
| `LITERATURE_correlated_patterns.md` | Literature notes behind the correlated-pattern experiments. |
| `OVERNIGHT_PLAN.md` | Planning record for the long resumable campaigns. |

The V5 campaign write-ups (`N1`–`N10`) are separate and live in
`data/v5_campaigns/SYNTHESE_NUMERICAL_WORKPLAN.md` and `RUN_STATUS.md`.
